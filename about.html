My story

It started with an old computer that nobody was using. I turned it into a home server and ran a Minecraft server on it for my friends. Keeping it online taught me more than any tutorial — how to access it remotely, open it up to the internet safely, and fix it when things broke.

That got me curious about how networks really work, which led me into cyber security. Now I run a small security lab at home where I practise attacking my own machines and building alerts that catch it.

I also enjoy programming — I made a chess game in Python and an app in C++ that sends files securely between computers. And when friends or family have a broken laptop, I'm usually the one they call.

I'm open to IT internships and I'm very open to learning — I'm always looking for the next thing to figure out.
