Who I Am

about.txt

I'm a Computer Science & Cyber Security student building my foundation through both academic study and hands-on projects. I created this website myself as a practical project to apply what I've been learning.

I'm actively learning networking concepts and using Wireshark to analyse network traffic and understand how protocols work at the packet level.

I've been learning Linux (Ubuntu) and put that knowledge into practice by building a home server from an old machine. I used it to host a Minecraft server for friends, which taught me real-world server administration: port forwarding, SSH remote management, service configuration, and keeping a system running 24/7.

I also enjoy troubleshooting laptops for friends and family, fixing hardware issues and diagnosing software problems. That hands-on work keeps me learning about how systems actually function under the hood.
